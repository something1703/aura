# Decision Framework

AURA evaluates every candidate through four layers.

## Layer 1 — Eligibility

Does the architecture satisfy mandatory requirements?

## Layer 2 — Resilience

How does it behave under declared failure scenarios?

## Layer 3 — Economics

Is it viable under the workload and budget assumptions?

## Layer 4 — Trade-offs

Among eligible designs, which offers the strongest overall balance?

The final recommendation is therefore:

```text
Eligible candidates
        ↓
Reliability + Scale + Security + Cost + Operations
        ↓
Trade-off analysis
        ↓
Recommendation
```
